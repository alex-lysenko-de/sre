# Реализованные изменения

Строго по плану — замена строкового литерала пути в двух уже существующих
строках кода, без изменения окружающей логики, условий, сигнатур функций
или структуры компонентов:

1. `LoginView.vue`, `redirectToHome()` — теперь действительно ведёт на
   `/main` (домашнюю страницу), а не на `/info`. Вызовы этой функции (в
   `onMounted()` при обнаружении активной сессии и в конце `handleLogin()`
   после успешного входа по паролю) не менялись — дефект был только в теле
   самой функции.
2. `WelcomeView.vue`, обработчик успешного авто-логина внутри
   `handleRegister()` — после `setAuthItem('sre_user_registered', 'true')`
   теперь `router.push('/main')` вместо `router.push('/info')`. Порядок
   операций (флаг → редирект) и соседняя ветка обработки ошибки
   авто-логина (`router.push('/login')`) не затронуты.

`src/router/index.js` не менялся — согласно плану, каскадных редиректов в
`router.beforeEach` не обнаружено, изменений там не требовалось.

Явные ссылки на `/info` (`App.vue:91` — `router-link to="/info"` в меню,
`MainView.vue:218` — `goToInfo()`) и гостевой редирект на `/info` в
`router/index.js` (строки ~187-189) — не изменены, проверены `grep`
после правки, поведение не затронуто.

  существующие предупреждения о размере чанков не связаны с этой правкой
