# Реализованные изменения

Во всех четырёх файлах, в точности по IMPLEMENTATION_PLAN.md:

* Добавлена одна новая модульная (не `ref`) переменная `hasLoadedOnce = false`
  рядом с уже существующими `realtimeChannel`/`reloadDebounceTimer`.
* Тело функции `load()` обёрнуто в `try/finally`:
  * `loading.value = true` теперь выставляется только условно —
    `if (!hasLoadedOnce) loading.value = true`.
  * `loading.value = false` перенесено в `finally` — гарантированно
    выполняется как при успехе, так и при исключении внутри `load()`
    (закрывает Minor 3 из ревью 143).
  * `hasLoadedOnce = true` ставится **в конце `try`** (не в `finally`) —
    только после успешного завершения загрузки, а не при исключении, чтобы
    следующая попытка после сбоя первой загрузки снова показала
    полноэкранный спиннер.

* **`CheckpointListView.vue`**: линейная структура без ветвления,
  `hasLoadedOnce = true` — сразу после заполнения `results.value`.
* **`CheckpointBusView.vue`** / **`CheckpointGroupView.vue`**: структура с
  ранним `return` (ветка "checkpoint не найден"). `hasLoadedOnce = true`
  проставлено в **обеих** точках выхода из `try` — в ветке "не найден" (перед
  `return`) и в конце основной успешной ветки — как предписано планом
  (раздел "Изменения существующих компонентов" для этих двух файлов).
* **`CheckpointLazyView.vue`**: структура `if (checkpoint.value) {...}` без
  раннего `return`, `hasLoadedOnce = true` — один раз, сразу после
  `if`-блока, перед `finally`.

Шаблоны (`v-if="loading"`), `debouncedReload()`, `setupRealtimeSubscription()`,
`onUnmounted()`, сигнатуры и вызывающие места `load()` — не изменялись,
как и предписано планом.

# Проверки

* `npm run build` — сборка прошла успешно без ошибок (единственное
  предупреждение — про размер чанка `index-*.js` > 500 kB, не связано с
  этой правкой и присутствует независимо от неё).
* Просмотрены diff'ы всех четырёх файлов — изменения ограничены телом
  `load()` и одной новой переменной `hasLoadedOnce` в каждом файле, как
  того требует Definition of Done плана.
* Ручная проверка на устройстве/в браузере (Slow 3G, несколько сканов
  подряд с другого устройства, удаление checkpoint во время просмотра,
  провоцирование исключения в `load()`) — **не выполнена в рамках этой
  сессии**, требует ручного окружения браузера/устройства и другого
  клиента для генерации Realtime-событий. Остаётся на усмотрение
  пользователя перед переводом в ревью/на прод, как и для предыдущих
  тикетов серии Checkpoint (нет автотестов для этих экранов).
