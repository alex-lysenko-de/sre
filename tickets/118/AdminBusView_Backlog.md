# Backlog: предложения по доработке AdminBusView.vue

Извлечено из `doc/AdminBusView_TechTask.md` (раздел «🔧 Предложения по доработке»)
перед удалением файла в рамках тикета 118 — само содержание файла (алгоритмы
подсчёта, структура таблиц, триггеры, reset-операции, realtime) покрыто
`vault/05-API-Composables/useBusData.md` и `vault/03-База-данных/Триггеры.md`,
но эти нереализованные идеи нигде в `vault/` не задокументированы.

Список ниже — нереализованный backlog, не техническое задание к исполнению.

## Задача 1: Детализированная статистика по автобусам

Отдельный блок после "Total Summary Card": карточка на каждый автобус с
количеством детей, воспитателей и соотношением "дети/воспитатель".

## Задача 2: Фильтрация автобусов

Переключатель над таблицей: показывать все автобусы / только активные /
только пустые.

## Задача 3: История изменений за день

Разворачиваемая панель (после ResetHistoryPanel) с таймлайном последних
сканирований и reset-событий за текущий день.

## Задача 4: Экспорт данных

Кнопка "Exportieren" рядом с "Aktualisieren" — выгрузка текущей сводки по
автобусам в Excel (.xlsx), PDF и CSV.

## Задача 5: Поиск по детям

Поле поиска по имени ребёнка над таблицей автобусов, с подсветкой
соответствующей строки автобуса в результатах.

## Задача 6: Улучшение мобильной версии

Адаптивная карточная раскладка автобусов для мобильных экранов (вместо
таблицы) + touch-friendly размеры кнопок.

## Задача 7: Уведомления о проблемах

Панель предупреждений: слишком много детей на одного воспитателя, автобус
без воспитателя, не все автобусы заполнены, день ещё не начат.
