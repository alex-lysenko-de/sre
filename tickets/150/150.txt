# Ticket 150. Armband-Zuordnung: список выбора ребёнка — разбить строку на несколько

## Описание проблемы

На странице привязки браслета (`ArmbandView.vue`, route `/armband/:id` —
экран "Armband-Zuordnung") список детей группы, из которого воспитатель
выбирает ребёнка для привязки, выводит всю информацию о ребёнке одной
строкой:

```
{{ child.name }} ({{ child.age }} J) — Armband: {{ child.band_id ?? '—' }}
```

(`src/views/ArmbandView.vue`, строки 56-59).

На маленьком экране телефона такая строка легко переносится браузером
как попало и плохо читается — сложно быстро найти нужного ребёнка в
списке во время сканирования.

## Требуется

Разбить информацию о ребёнке в каждом пункте списка на несколько строк,
например:

```
Max Mustermann
Alter: 10
Armband Id: 104
```

Radio-button и логика выбора (`v-model="selectedChildId"`) не меняются —
меняется только вёрстка содержимого `<label class="form-check-label">`.

## Критерии приемки

* в списке "Kind auswählen" каждый пункт показывает имя, возраст и ID
  браслета на отдельных строках (не в одну строку через тире/скобки);
* выбор ребёнка (radio) и последующая привязка браслета работают как
  раньше;
* список остаётся читаемым на мобильном экране (проверить на реальном
  устройстве или в узком viewport).
