# CLAUDE.md

Компактная справочная сводка проекта для ИИ-ассистента (Claude Code) —
восстановление контекста после сброса/сжатия сессии. Не пересказывает
полную базу знаний — только нетривиальные факты, не выводимые тривиально
чтением кода. Полная база знаний: **`vault/00-Индекс/MOC.md`**.

## Предметная область

Учёт детей и переклички на мероприятиях (Stadtranderholung): регистрация
детей/воспитателей по группам и автобусам, сканирование браслетов,
подсчёт присутствия в реальном времени.

## Стек

Vue 3, Pinia, Supabase, LocalForage, Vite/PWA — см. `package.json` за
точными версиями зависимостей.

## Архитектурные соглашения

- Слоистая структура для доменной логики: `stores/useXXX` (состояние,
  без бизнес-логики) → `composables/useXXX` (бизнес-логика, кэширование)
  → `composables/useSupabaseXXX` (доступ к Supabase). См.
  `vault/04-Пользователи-и-аутентификация/stores-user.md`.
- Целевая архитектура (API-адаптер, Cloud/Local Mode) пока **не
  реализована** — фронтенд обращается к Supabase напрямую. См.
  `vault/01-Архитектура/Целевая-архитектура.md`.

## Ключевые факты о модели данных

- `group_id`/`bus_id` в `userInfo` — поля **на сегодня** из
  `user_group_day`, не персистентные атрибуты пользователя.
- Таблиц `groups`/`buses` не существует — это просто smallint-номера
  `1..config.total_groups` / `1..config.total_buses`.

## Активное ограничение: секреты в `doc/`

Три файла содержат реальные секреты в открытом виде и **не подлежат
изменению, удалению или переносу содержимого куда-либо ещё** (включая
`vault/` и этот файл):

- `doc/sb_install_keys.bat` (реальный Supabase `service_role` key)
- `doc/supabase_install.md` (тот же ключ)
- `doc/users.sql` (реальные email/телефон/пароль администратора-бутстрапа)

## Конвенция работы с тикетами

`tickets/<N>/<N>.txt` → `IMPLEMENTATION_PLAN.md` → `IMPLEMENTATION_REPORT.md`
→ `REVIEW_REPORT.md`, статус — в `tickets/<N>/state.txt`. После создания
тикета или смены статуса — обновить `tickets/dashboard.md`.

**Перед присвоением нового номера тикета** — свериться и с `tickets/`, и с
`git log --oneline --grep <номер>`: номер иногда уже занят в тексте
git-коммита без соответствующей папки в `tickets/` (пример: коммит
`17e206d "111: add DB backup tooling"` — коллизия обнаружена и исправлена
при работе над тикетом 118, см. `tickets/dashboard.md`).
